# NEXORA AI Academy

An interactive Persian-first AI learning school: AI foundations, Python, Math for AI, Machine Learning, Deep Learning, LLMs, RAG, Agents, Computer Vision, projects, interactive labs, progress tracking, PWA and optional server-side AI tutoring.

## Verify
`npm run typecheck`
`npm test`
`npm run build`

## AI Tutor
Set `OPENAI_API_KEY` and/or `GEMINI_API_KEY` as server-only environment variables. The browser never receives these keys.
